# Click Before Frames

A Geode mod for Geometry Dash 2.2081 (Windows). A from-scratch recreation of the Click Before Frames idea by vVexis, with the same features, menus, settings and defaults.

- **Cube, ball, robot, spider:** early clicks in the air are simulated ahead and held until they're safe. Ground and orb clicks are never delayed.
- **Ship, UFO, swing, wave:** very short taps are stretched to a minimum length.
- **V button** on every screen (drag to move, tap for the menu): mode OFF / LOW / MED / HIGH, per-gamemode toggles, live stats, settings. The pause menu has a V button too.

Not legit for lists or leaderboards.

## Building

Push to GitHub and the included workflow builds it. Download **Click Before Frames** from the Actions tab and put the `.geode` file inside it in `Geometry Dash\geode\mods\`.
